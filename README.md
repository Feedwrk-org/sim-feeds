# SIM supplier feeds

Test feeds for the Feedwrk use case simulator (SIM). Four made-up suppliers, 30 items each, with planted data problems that real supplier feeds have.

| Feed | Supplier | Shape |
|---|---|---|
| [nordhem-living.xml](feeds/nordhem-living.xml) | Nordhem Living | Shopify-style export, one long HTML description |
| [lumo-light.xml](feeds/lumo-light.xml) | Lumo Light | Dutch keys, each colour a separate item |
| [kasa-ceramics.xml](feeds/kasa-ceramics.xml) | Kasa Ceramics | Google Merchant RSS |
| [atelier-tekstil.xml](feeds/atelier-tekstil.xml) | Atelier Tekstil | German wholesale list (used as a file upload) |

Brands and product names are invented. Product photos are from luumaform.com. Not for use outside Feedwrk testing.

The answer key (defect map and golden records) is kept outside this repo so runs stay blind.
